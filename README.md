# 智能穿搭色彩系统（系统原型）

> 解决你的每日穿搭烦恼，让 AI 为你定制专属色彩方案。
> 依据《智能穿搭色彩系统》PPT 的 7 大功能与论文的 4 层架构实现的可运行原型。

## 功能

| 模块 | 说明 |
|------|------|
| 首页 | 系统核心功能与价值总览 |
| 我的衣橱 | 录入上衣/下装/裙装/外套/鞋/配饰，建立数字化衣橱 |
| 个人档案 | 肤色冷暖、发色深浅、穿搭风格、不喜欢颜色 |
| 穿搭推荐 | 选择天气/场合/季节，一键生成 2~3 套方案（含适配度评分 + 推荐理由） |
| 色彩知识 | 色相环、和谐配色规则、配色避坑提示 |

## 运行

```bash
# 安装依赖（国内可用清华镜像）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 启动
streamlit run app.py
```

浏览器会自动打开 `http://localhost:8501`，侧边栏可切换 **中文 / ไทย**。

## 目录结构

```
穿搭色彩系统/
├── app.py           # Streamlit 前端（表现层 + 应用/工作流层）
├── recommender.py   # 推荐引擎（智能核心层）
├── color_engine.py  # 色彩解析与和谐度规则（智能核心层）
├── data.py          # 数据层：示例衣橱 + JSON 持久化
├── i18n.py          # 中泰双语文案
├── user_data.json   # 运行时自动生成（衣橱/档案持久化）
└── requirements.txt
```

## 推荐逻辑（可解释）

每套方案的适配度由以下维度加权得出，并附带推荐理由：

1. **两两和谐度**（同色系 / 中性打底 / 互补点缀 / 高饱和撞色冲突）
2. **肤色适配**（冷皮→冷调色，暖皮→暖调色）
3. **场合适配**（商务低饱和、聚会高饱和……）
4. **天气适配**（阴天浅色提亮、低温深色保暖……）
5. **季节适配**（春马卡龙、秋大地色……）
6. **风格适配**（极简莫兰迪、复古大地色……）
7. **避坑规则**（全身主色 ≤3 种、自动避开不喜欢的颜色）

## 数据持久化

衣橱与个人档案保存在 `user_data.json`，删除该文件即可恢复默认示例衣橱。
